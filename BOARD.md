## How It Works

1. **Eric** creates a [GitHub Issue](https://github.com/EricManintveld/openclaw-website/issues) describing a feature
2. **Sam** detects the new issue, moves it to **In Progress**, and spins up a sub-agent
3. Sub-agent builds the feature, pushes to a branch, creates a PR
4. Item moves to **Awaiting Approval** — Eric gets a one-click PR link
5. Eric reviews & merges the PR → the site updates automatically via GitHub Pages
6. Item moves to **Done** 🎉
